RecoveryMeasures

object RecoveryMeasures(source)

Computes how close a fitted mixture is to the truth.

Density distance is the primary measure, not family labels. A mixture of heterogeneous families need not have identifiable family labels at all: an exponential is a gamma of shape one and a Weibull of shape one, and a uniform is a beta with both shapes one, so a recovery measure keyed on the label would report failures that are not failures. Distance between densities is invariant to that relabeling, which is why it leads.

Family recovery is still reported, but against equivalence classes rather than exact labels, and only when the component counts agree so that a matching exists.
