ProblemConstraintTableData
Link copied to clipboard
data class ProblemConstraintTableData(var expId: Int = -1, var problemName: String = "", var responseName: String = "", var rhsValue: Double = 0.0, var inequalityType: String = "", var target: Double = 0.0, var tolerance: Double = 0.0) : DbTableData

One row per (experiment, problem, response constraint): the constraint as the problem defines it. Without these rows the database records what a run achieved but not what it had to meet, so answering "was every verified winner feasible?" meant hand-coding the constraint table from the specification and joining it externally. With them the question is a single join and the archive is self-describing.
